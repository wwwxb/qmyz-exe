QMYZ 青马易战 刷题助手 v1.0.0（Windows 绿色便携版）
=====================================================

一、这是什么
    本程序是 GitHub 项目 shibig666/QMYZ 的 Windows 便携打包版：
    - 原项目代码未做任何修改（fight.py / qm_cli.py / qm_auto.py / qm_utils 原样保留在包内）；
    - 仅新增一个图形界面 gui.py，方便不想敲命令行的人使用；
    - 已内置 Python 运行环境和 15 个课程题库（约 1.2 万题），无需安装 Python。

二、怎么用（不需要安装，解压即用）
    1. 把整个文件夹解压到任意位置（例如 D:\QMYZ）；
    2. 双击 QMYZ.exe；
    3. 在浏览器里登录“易班-青马易战”，进入首页（带视频的那个页面），
       把地址栏里的长地址整段复制（这就是“登录URL”，其中含 JSESSIONID）；
    4. 回到程序：点“粘贴” → 点“获取课程” → 在下拉框里选课程；
    5. 设置“答题量”（0 表示一直答到手动停止）和“准确度”，点“开始刷题”。

三、目录说明
    QMYZ.exe            主程序（无控制台窗口）
    _internal\          运行环境，不要删、不要移动（删了就打不开）
    _internal\qmyz\     内置题库（*.csv）
    LICENSE.txt         上游项目的 GPLv3 许可证
    源码获取说明.txt     开源合规说明

四、更新题库（重要）
    程序查找题库的顺序是：
        1) QMYZ.exe 同级的 qmyz\ 目录（你自己放的，优先）
        2) _internal\qmyz\（内置题库）
    所以更新题库不需要重新打包：把新的 `<课程ID>.csv` 放到 QMYZ.exe 旁的 qmyz\ 文件夹即可。
    也可以点界面上的“打开题库目录”直接跳转过去。

五、常见问题
    Q: 双击没反应 / 一闪而过？
    A: 先看是否被 360、火绒、Defender 拦截（PyInstaller 打包的程序容易被误报），
       加入信任后重试；仍不行请把完整目录解压后再运行，不要只拷 exe。

    Q: 提示“获取课程失败”或“获取cookie失败”？
    A: 说明 URL 里的登录态过期了。重新在浏览器登录平台，再复制一次地址。

    Q: 提示“本地没有该课程题库”？
    A: 该课程还没人做过题库。可以先用上游的 fight.py 自动对战来爬题（命令行用法见 README.md）。

    Q: “准确度”是什么意思？
    A: 原项目的策略：当累计准确率低于设定值时按题库答案答；一旦高于设定值，
       就随机选一个答案（用于把正确率压下来，避免 100% 显得异常）。设 100 表示全程按题库答。

    Q: 会不会封号？
    A: 程序按 3~6 秒随机间隔答题并伪装浏览器请求头，但平台风控无法保证。
       使用风险由使用者自行承担。
